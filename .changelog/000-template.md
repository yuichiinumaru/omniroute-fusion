# Changelog Entry Template

Filename format:
`YYYYMMDD-HHMMSS-NNNN-taskname-agentname.md`

Frontmatter format:
```yaml
---
date: YYYYMMDD-HHMMSS
timestamp: YYYYMMDD-HHMMSS
project: ganthritor
agent: your-agent
task: "NNNN"
description: "Short change description"
is_rebuild_safe: true
---
```

Required body sections:
1. `# Task NNNN: Title`
2. `## Summary`
3. `## Changes`
4. `## Verification`
